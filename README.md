# Skinstric AI App 

Solo Internship Project - challenge was to create a routed app that collects user name and ethnic origin and invites user to either upload their facial image or allow a screen capture of their face. The captured image is uploaded to a backend API and resultant ethnicity data is returned and displayed for user to confirm or adjust. Not part of the internship project was using the confirmed demographics to generate a recommended facial treatment. The design format, colors and layout was provided in a Figma file and had to be adopted in the project.

---

## 🚀 Features

* **Welcome / Basic Info Collection:** User inputs their name, ethnic origin & facial image upload/capture.
* **Pre-Facial Treatment AI-based demographic assessment:** Render API sourced demographic information and get user to confirm or change/save.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** Typescript / JavaScript (ES6+)
* **Styling:** HTML, Tailwind CSS (Responsive & Utility Design), Figma-based UX Design 

---

## ⚙️ Getting Started

### Prerequisites

Ensure you have **Node.js (v18.x or higher)** and npm/yarn installed locally.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/HiraniDotCom/msh-skinstric
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open http://localhost:5173 in your browser to see the dashboard.
